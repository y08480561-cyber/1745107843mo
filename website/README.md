# 🏆 پنل مدیریت مستقل وب «رقابت کن، جایزه ببر»

این پروژه یک **سایت مستقل و حرفه‌ای** برای مدیریت کاربران، امتیازها و نظارت بر مسابقه است که کاملاً جدا از اپلیکیشن اندروید طراحی شده است و به پایگاه داده مشترک **Supabase** متصل می‌شود.

---

## 🎨 ویژگی‌ها و امکانات
1. **طراحی مدرن و واکنش‌گرا**: رنگ‌بندی حرفه‌ای سرمه‌ای (`#0B192C`)، آبی (`#1E3E62`) و طلایی (`#FFB703`) با فونت فارسی وزیرمتن و راست‌چین کامل (RTL).
2. **احراز هویت امن مدیر**: ورود به سیستم با ایمیل و رمز عبور از طریق **Supabase Auth** و بررسی سطح دسترسی از طریق تابع امن پایگاه داده (`is_admin`).
3. **فهرست پیشرفته کاربران**: نمایش نام، نام خانوادگی، امتیاز کل، وضعیت حساب و تاریخ ثبت‌نام.
4. **حریم خصوصی و امنیت**: شماره‌های موبایل کاربران به صورت ماسک‌شده (`0912***3456`) نمایش داده می‌شوند تا اطلاعات شخصی در معرض دید عموم نباشد.
5. **جستجوی زنده**: جستجوی سریع کاربران بر اساس نام یا شماره همراه.
6. **آمار کلیدی زنده**: نمایش تعداد کل کاربران، مجموع امتیازهای اعطا شده، تبلیغات امروز و مسابقات فعال.

## 🚀 راهنمای راه‌اندازی و اتصال به Supabase

### ۱. اجرای محلی (Local Development)
برای اجرای سایت روی سیستم خود:
1. پکیج‌های پروژه را نصب کنید:
   ```bash
   npm install
   ```
2. سرور توسعه را اجرا کنید:
   ```bash
   npm start
   ```
3. مرورگر را باز کرده و به آدرس `http://localhost:3000` بروید.

### ۲. اتصال به پروژه Supabase
در صفحه ورود پنل مدیریت، اطلاعات زیر را وارد کنید:
- **Project URL**: آدرس پروژه Supabase شما (مثلاً `https://xyz.supabase.co`)
- **Anon / Public Key**: کلید عمومی `anon` پروژه شما
- **ایمیل و رمز عبور مدیر**: ایمیلی که در جدول `admin_users` پایگاه داده خود ثبت کرده‌اید.

## 📦 راهنمای انتشار رایگان (Deployment)

این سایت یک برنامه وب کاملاً استاتیک است و می‌توانید آن را به صورت **رایگان** روی سرویس‌های زیر منتشر کنید:

### الف) انتشار روی Vercel (توصیه شده)
1. وارد [Vercel](https://vercel.com) شوید.
2. پوشه `website` را به صورت Drag & Drop آپلود کنید یا به گیت‌هاب متصل کنید.
3. دکمه Deploy را بزنید. سایت شما آنی روی دامنه رایگان قرار می‌گیرد.

### ب) انتشار روی Netlify
1. وارد [Netlify Drop](https://app.netlify.com/drop) شوید.
2. پوشه `website` را درون کادر رها کنید تا در چند ثانیه سایت شما منتشر شود.

## 🔒 نکات امنیتی مهم
- کلید محرمانه `service_role` به هیچ عنوان در این کد استفاده نشده است تا امنیت پایگاه داده شما کاملاً حفظ شود.
- دسترسی به جدول‌ها از طریق سیاست‌های امنیتی **Row Level Security (RLS)** پایگاه داده Supabase محافظت می‌شود.
